# MIRRAI 原型前端

纯静态前端，没有构建步骤。大屏按 55 寸竖屏 9:16 设计，逻辑画布 1080 × 1920，在任意窗口里等比缩放。

运行方式见项目根目录的 `README.md`。

## 页面

| 页面 | 说明 |
|---|---|
| `index.html` | 演示外壳：左边大屏，右边模拟扫码、服务状态、埋点事件流 |
| `kiosk.html` | 大屏本体，可以单独全屏放到真屏上 |
| `m.html` | 手机页，扫大屏二维码打开；参数只含款式、尺码、会话号和随机 token |
| `shop.html` | 演示用"品牌官网"商品页 |

## 流程

大屏：P0 待机轮播 → P1 拍脸（可跳过）→ P2 身高 / 尺码 → P3 选款画廊（形象在后台生成）→ P4 生成中（推荐 3 套搭配）→ P5 效果页 → P6 扫码交接 → P7 清空。
手机：我的试穿 → 单品详情（叫店员 / 官网购买）→ 分享海报 → 删除记录。

## 文件

| 文件 | 作用 |
|---|---|
| `data.js` | 16 件虚构商品（价格、货架、库存）、8 套推荐搭配 L1–L8、尺码映射 |
| `kiosk.*` | 大屏：状态机、摄像头与端侧人脸检测、调用生成服务、60 秒空闲清空、二维码 |
| `m.*` | 手机页：试穿结果、优惠券、单品详情、Canvas 海报、删除 |
| `index.html` / `shell.*` | 演示外壳，通过 postMessage 与大屏通信 |
| `assets/products/` | 16 件单品图 |
| `assets/tryon/` | 默认模特（M、XL）与 8 套搭配 × 2 个体型的试穿图；`.webp` 供页面展示，`.png` 是生成服务的参考图 |
| `assets/shoes/` | 3 双造型鞋（运动鞋、及膝长靴、乐福鞋），只作生成参考，不出售 |

## 说明

- 生成服务不可用时（纯静态部署、无 Key、超出限流），自动改用预生成的试穿图；没有预生成图的组合展示官方商品图。
- 人脸检测使用 MediaPipe，在浏览器本地运行；加载失败时不做检测，直接允许拍照。
- 全部商品、模特和试穿图均由 AI 生成，为虚构内容。库存、领券、叫店员、下单为模拟功能。
