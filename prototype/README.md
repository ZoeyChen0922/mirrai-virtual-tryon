# MIRRAI · 门店 AI 虚拟试衣大屏原型 v1.0

纯静态前端原型，没有构建步骤。大屏按 55 寸竖屏 9:16 设计，逻辑画布 1080 × 1920，在任意窗口里等比缩放；放到真屏上缩放比例正好是 1。

## 运行

**真实生成模式**（推荐）：拍照后用你的脸生成效果图。需要在项目根目录的 `.env` 里放 `OPENAI_API_KEY`。

```bash
python3 tools/server.py
```

然后打开 `http://localhost:4174`。同一 Wi-Fi 下的手机可以扫码打开手机页，服务会自动把二维码里的地址换成本机局域网 IP。

**纯静态模式**（没有 Key，或部署到 GitHub Pages 时）：自动改用预生成的示例形象。

```bash
cd prototype && python3 -m http.server 4173
```

| 页面 | 地址 | 说明 |
|---|---|---|
| 演示外壳 | `http://localhost:4173/` | 左边是大屏，右边是异常情景开关、模拟扫码、埋点事件流 |
| 大屏本体 | `/kiosk.html` | 可以单独全屏，放到真屏上用 |
| 手机页 | `/m.html?...` | 扫大屏上的二维码打开，参数只含款式 id 和尺码 |

部署到 GitHub Pages 之后，用手机扫大屏上的二维码就能直接打开手机页。

## 流程

P0 待机视频 → P1 拍脸（可跳过）→ P2 性别 / 身高 / 尺码 → P3 选款画廊（形象在后台生成）→ P4 生成中 → P5 效果页 → P6 扫码交接 → P7 清空。
手机端：我的试穿 → 商品详情（叫店员 / 官网购买）→ 分享海报 → 删除记录。

## 模拟与隐私说明

- 以下都是模拟：AI 生成、库存、领券、叫店员、下单。
- 没有提前准备素材的搭配组合，会按"生成失败"的降级逻辑展示官方商品图。
- 真实生成模式下，照片会发给本地服务，再由服务转发给 OpenAI 图像接口，只用于本次生成。原图不保存；生成结果只放在服务内存中，24 小时后删除，大屏清除或手机端删除时也会一起删除。
- 慢速、失败、断网三种情景仍然是模拟的，方便评审现场稳定演示。
- 二维码链接里只有款式、尺码、会话号和一个随机 token，不含人脸。
- 人脸检测用的是 MediaPipe（在浏览器本地运行，WASM）。加载失败时不做检测，直接允许拍照。
- 商品图、名称和链接来自 Zara 官网，价格是演示价。仅用于笔试原型演示，版权归 Inditex / Zara 所有，本原型与 Zara 无关联。
